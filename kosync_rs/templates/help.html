Connect an e-reader

Sync reading positions with KOReader and browse the library from any OPDS-capable reading app.

{{ icons::icon(name="sync") }}KOReader progress sync

  1. Open the sync settings

    In KOReader, open a book, then go to Tools → Progress sync → Custom sync server.

  2. Enter this server's address
    http://<server>:8090
  3. Register or log in

    Choose Register / Login and use the same username and password you use on this site.

  4. Sync

    Turn on automatic sync, or choose Push progress. The book will show up under Reading progress.

{{ icons::icon(name="rss") }}OPDS catalog

Add a catalog in your reading app to browse and download books from the shared library.

OPDS 1.x (KOReader and most e-readers)
http://<server>:8090/opds/

OPDS 2.0 (Readium-based and newer apps)
http://<server>:8090/opds/v2/

OPDS uses HTTP Basic auth. Sign in with the same username and password you use for syncing.

{{ icons::icon(name="help") }}Good to know

  • The server root (/) serves this web interface, not OPDS. Point e-readers at /opds/.
  • Books are matched to your reading progress by KOReader's partial MD5 document digest, so a book downloaded from the library picks up where you left off.
  • HTTP Basic auth sends credentials in cleartext. Put this server behind a TLS reverse proxy before exposing it to the internet.
